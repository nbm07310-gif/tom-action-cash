3 formules financières importantes

1) Intérêt simple

Montant A après une durée t :

\(A = P\,(1 + r\,t)\)

P = capital initial, r = taux annuel (ex : 0.05), t = durée en années

2) Intérêt composé

Montant A après n périodes par an :

\(A = P\left(1 + \frac{r}{n}\right)^{n t}\)

P = capital, r = taux annuel, n = périodes par an, t = années

3) Mensualité d'un prêt

Paiement périodique pour rembourser un prêt :

\(M = P\,\frac{r(1+r)^n}{(1+r)^n - 1}\)

P = principal, r = taux périodique, n = nombre de périodes

Conseil : remplacez P, r, n par vos valeurs pour calculer rapidement.
