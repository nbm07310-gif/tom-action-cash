3 formules financières importantes

1) Intérêt simple

Montant après durée t :

\(A = P\,(1 + r\,t)\)

P = capital initial, r = taux (annuel), t = temps (années)

2) Intérêt composé

Montant après n périodes par an :

\(A = P\left(1 + \frac{r}{n}\right)^{n t}\)

P = capital, r = taux annuel, n = nombre de périodes par an, t = années

3) Mensualité d'un prêt

Paiement mensuel pour un prêt amortissable :

\(M = P\,\frac{r(1+r)^n}{(1+r)^n - 1}\)

P = principal, r = taux périodique, n = nombre de périodes
